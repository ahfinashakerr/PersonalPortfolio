Animated concepts

Three small animations used across this site. Each one has a short note on how it works.

1. Animated text

I am a Web Developer
How it works

JavaScript adds one letter at a time with setTimeout, waits, deletes the letters and moves to the next phrase. The blinking cursor is a CSS keyframe animation on the right border.
